【DS 助手 · 安装使用说明】（2 分钟搞定）

━━━━━━━━━━━━━━━━━━
一、安卓手机（两步装好）
━━━━━━━━━━━━━━━━━━
1. 下载「DS助手-官方同款-v1.0.apk」→ 点击安装
   （提示"未知来源"→ 点「仍要安装」即可，本 App 无任何广告和后台）
2. 打开 App

━━━━━━━━━━━━━━━━━━
二、配 Key + 充值（一次性，两分钟）
━━━━━━━━━━━━━━━━━━
1. 浏览器打开 platform.deepseek.com 用手机号注册（官方平台，免费注册）
2. 左侧「API Keys」→ 创建 → 复制 sk- 开头的一串字符
3. 回到 App → 点「⚠️ 配置 API Key」→ 粘贴 → 保存
4. 点「⚡ 充值」→ 支付宝/微信扫码 → 最低 1 元，秒到账
5. 点「💰 余额」确认到账 → 开聊！

━━━━━━━━━━━━━━━━━━
三、原理（为什么网页限额不管用）
━━━━━━━━━━━━━━━━━━
网页版限额限的是「网页免费额度」。
本 App 走的是官方 API 接口，按量计费、充多少用多少，
两个池子互不影响。充 10 块钱能聊很久
（deepseek-chat 约 ¥2/百万字输出）。

━━━━━━━━━━━━━━━━━━
四、想用「原版官方 App」的同学
━━━━━━━━━━━━━━━━━━
下载「DS官方App-API补丁模块.apk」，配合 LSPatch 使用：
1. 手机装 LSPatch（GitHub 搜 LSPatch 下载，免 root）
2. LSPatch → 新建修补 → 选官方 DeepSeek App 安装包
3. 修补模式：本地模式 → 嵌入「DS官方App-API补丁模块」
4. 修补安装 → 打开后填 Key → 界面 100% 官方原版，流量走 API

━━━━━━━━━━━━━━━━━━
常见问题
━━━━━━━━━━━━━━━━━━
· 报 401 → Key 填错/被删，去平台重看
· 报 402 → 余额不足，App 里点 ⚡ 充值即可
· 连不上 → 换个网络，API 服务器在境外偶尔抖动
· 苹果手机 → 用网页版（见视频简介里的网页链接），
  Safari 打开 → 分享 → 添加到主屏幕，和 App 一样用
